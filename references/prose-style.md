# Prose Style Guide

Capture the writer's own prose style from samples, then use that profile to maintain
consistency across the manuscript, flag stylistic drift, or write new passages in their voice.

This is not about correcting the writer's style. It's about understanding and preserving it.

---

## Modes

### Mode 1: Build a Style Profile

Writer provides prose samples (ideally 500–2000 words they're happy with). You extract
a fingerprint of their style.

**Process:**
1. Read all samples before extracting anything.
2. Look for patterns, not individual choices. One long sentence means nothing.
   Ten long sentences is a style.
3. Build the profile using the schema below.
4. Present the profile to the writer and ask them to confirm or correct it.
   They know their own intentions — you're surfacing the patterns, they validate.

### Mode 2: Style Consistency Check

Writer provides a new passage and their style profile. You check for drift.

**Process:**
1. Read the passage.
2. Compare against each profile dimension.
3. Flag specific lines that depart from the profile.
4. Distinguish *intentional* variation (the writer made a choice) from *accidental* drift.
   When in doubt, flag it as a question, not a verdict.

**Report format:**
> 📌 STYLE DRIFT — [Dimension]: "[exact line]"
> Profile establishes [X]. This reads more like [Y]. Intentional?

### Mode 3: Write in the Writer's Style

Writer asks you to draft a passage, continue a scene, or write a placeholder in their voice.

**Process:**
1. Load the style profile. If none exists, build one from provided samples before writing.
2. Draft the passage using the profile as a constraint.
3. After the draft, note which profile elements you leaned on most heavily.
4. Offer to adjust — first drafts in someone else's voice are rarely perfect.

**Important:** Always flag this as a draft for the writer to revise. You can approximate
their voice, but you cannot be them. The goal is a useful scaffold, not a finished passage.

## Style Profile Schema

```markdown
## Style Profile — [Author / Project Name]
**Sampled from:** [What texts were used]
**Sample size:** [approximate word count]

### Sentence Architecture
- **Typical length:** [short (avg <12 words) / medium (12–20) / long (20+) / highly variable]
- **Dominant structure:** [simple / compound / complex / fragment-heavy / mixed]
- **Paragraph rhythm:** [single-sentence paras / dense blocks / varied / breath-based]
- **Notable patterns:** [e.g., "often ends paragraphs with a short punchy sentence",
  "uses em-dashes for interruption frequently", "semicolons are rare"]

### Vocabulary & Diction
- **Register:** [plain/everyday / literary / elevated / academic / regional / period-specific]
- **Concrete vs. abstract:** [leans concrete / leans abstract / balanced]
- **Imagery domains:** [what categories of metaphor appear — nature, architecture, body, warfare, etc.]
- **Signature words/phrases:** [recurring language that feels like this writer]
- **Words/constructions they avoid:** [if observable]

### Interiority & Distance
- **Narrative distance:** [close (deep in POV's head) / mid / distant / variable]
- **Interiority style:** [explicit thought ("she thought...") / free indirect discourse / minimal]
- **Emotional expression:** [stated directly / shown through behavior / submerged / all three]

### Description & Pacing
- **Description density:** [sparse / moderate / lush / depends on scene type]
- **What they tend to describe:** [e.g., always describes light, rarely describes faces]
- **Dialogue-to-prose ratio:** [dialogue-heavy / prose-heavy / balanced]
- **Scene transitions:** [hard cuts / brief bridges / slow fades]

### Tone & Voice
- **Default narrative tone:** [e.g., wry / elegiac / urgent / detached / warm / cold]
- **Irony / humor:** [absent / dry / overt / situational]
- **Reader relationship:** [intimate / observational / conspiratorial / formal]

### Notable Stylistic Signatures
[List 3–5 things that make this writer's prose *theirs*. Be specific.]
- [e.g., "Tends to bury the emotional beat at the end of a long observation"]
- [e.g., "Uses present-tense interiority inside past-tense narration"]
- [e.g., "Similes often involve unexpected domestic objects"]
```

## Critical Rules

**Style ≠ correctness.** Fragment sentences, unconventional punctuation, and rule-breaking
are style choices. Do not flag them as errors. The profile captures what the writer *does*,
including the things that break rules.

**Small sample = provisional profile.** Under ~500 words, patterns are hard to distinguish
from random variation. Flag this and suggest the writer provide more samples before relying
on the profile for consistency checks.

**Ask before concluding.** If something appears in the samples but you're unsure if it's
intentional, ask. "I notice you use em-dashes to interrupt dialogue but never in narration —
is that intentional?" is better than silently encoding a rule that might be accidental.

**Writing in voice is hard.** When drafting in the writer's style, aim for "clearly influenced
by" rather than "indistinguishable from." Flag which elements you were trying to replicate
so the writer can see where the approximation breaks down.
